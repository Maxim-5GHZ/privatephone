«ПриватФон» — ПАК АСК: запуск в 30 секунд
===========================================

1. Скопируйте эту папку на машину оператора (Linux или Windows).
2. Вставьте USB-флешку с мастер-ключом — или просто пустую флешку,
   ключ создастся на ней автоматически при первом запуске.
3. Запустите:
     Linux:   двойной клик по  start.sh   (или в терминале: ./start.sh)
     Windows: двойной клик по  start.bat
4. Сервер сам создаст папку data/ (зашифрованная база, ключ оператора
   admin.pem, внутренний CA, TLS-сертификат) и начнёт принимать соединения.
5. В браузере откройте адрес, который сервер напечатает в консоли
   (вид: http[s]://<IP машины>:8080) и войдите оператором:
   файл data/admin.pem, позывной admin.
6. Абонентов заводите в интерфейсе: вкладка «Админ» → «Абоненты» →
   выдать позывной и скачать ключ на флешку абонента.

Важно:
- Мастер-ключ базы живёт ТОЛЬКО на USB-флешке. Не вынимайте флешку во время
  работы — сервер затрёт ключ и завершится.
- HTTPS по умолчанию включается автоматически (звонки/рация требуют
  secure context). На устройствах абонентов один раз импортируйте data/ca.crt
  как доверенный корень (Linux: sudo scripts/install_ca.sh data/ca.crt;
  Windows: Import-Certificate), чтобы не было предупреждения браузера.
- На Windows при первом запуске межсетевой экран спросит разрешение — разрешите.
- Для строгого боевого сценария (явные флаги, проверки) используйте
  «pp init» и «pp run -key <путь-на-флешке>».
