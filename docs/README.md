## Что такое ПАК АСК в двух абзацах

Автономная **offline**-система координации для группы: помеченная карта +
защищённый чат + тревоги + голосовые звонки и рация. Zero-зависимостей на хосте:
один статический бинарник Go со встроенным React-интерфейсом и офлайн-картой,
база данных зашифрована AES-256-GCM, мастер-ключ базы собирается из **двух
половин** — локальной `data/pp.local` на диске машины и USB-половины `pp.key`
на флешке. Рабочий ключ живёт только в RAM процесса (mlock) и при извлечении
флешки мгновенно затирается, узел завершает работу.

Каждый пакет подписан ECDSA P-256 и проверяется сервером; реплей-атаки
отсекаются (окно ±10 минут, anti-replay кэш). Содержимое — сообщения, метки,
тревоги, зоны — зашифровано **end-to-end**: сервер видит только обёртки-
шифротекст. Медиа идёт P2P (браузер ↔ браузер) поверх DTLS-SRTP, а поверх —
SFrame (E2EE-аудио). Сеть работает без интернета: узел — точка доступа Wi-Fi/
Ethernet для абонентских устройств.

## Глоссарий

| Термин | Определение |
|---|---|
| **Узел** | машина оператора, где работает бинарь `pp` (сервер+UI, HTTPS/WSS) |
| **Бинарь `pp`** | единый исполняемый файл (Go) со встроенным UI и тайлами карты |
| **data/** | папка данных узла рядом с бинарником: `vault.db`, ключи, сертификаты |
| **vault.db** | зашифрованная AES-256-GCM база (SQLite-снапшот) |
| **Мастер-ключ** | 32 байта, расшифровывающие vault; = SHA-256(половин) |
| **Половинки** | `pp.local` (на диске) + `pp.key` (на флешке); ни одна сама по себе базу не открывает |
| **Абонент** | пользователь системы с ECDSA-ключом; роль `operator` или `admin` |
| **callsign** | позывной абонента, уникальный идентификатор |
| **Пакет / Frame** | подписанное событие: маркер, сообщение, тревога, зона, сигнал |
| **Журнал** | tamper-evident цепочка хэшей всех принятых подписанных пакетов |
| **E2EE-конверт** | шифротекст, понятный только получателям (сервер — opaque) |
| **SFrame** | покадровое шифрование WebRTC-аудио поверх DTLS-SRTP |
| **Мешок (bag)** | экспортированный кусок журнала для переноса на другой узел (sneaker-net) |
